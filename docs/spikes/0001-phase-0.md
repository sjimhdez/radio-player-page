## R1 y R7: PHPUnit con la suite de tests de WordPress

Montaje (`spike/php/`): `composer.json` con `config.platform.php = 7.4.33`, `phpunit/phpunit ^9.6` y `yoast/phpunit-polyfills ^4.0`. wp-env ya trae la librería de tests de WP en `/wordpress-phpunit` y exporta `WP_TESTS_DIR`. El bootstrap carga el plugin en `muplugins_loaded`. Dos configuraciones de wp-env: `env-min` (`"core": "WordPress/WordPress#6.6-branch"`, PHP 7.4) y `env-latest` (`"core": null`, PHP 8.4).

| Combinación | PHP | WP | PHPUnit | Resultado |
|---|---|---|---|---|
| mínima | 7.4.33 | 6.6.10 | 9.6.38 | ✅ OK (2 tests) |
| última | 8.4.26 | 7.1.3 | 9.6.38 | ✅ OK (2 tests) |
| última | 8.4.26 | 7.1.3 | 11.5.57 | ❌ `Call to undefined method PHPUnit\Util\Test::parseTestMethodAnnotations()` en `abstract-testcase.php:592` |
| última | 8.4.26 | 7.1.3 | 12.5.40 | ❌ el mismo error |
| última | — | — | 10.x | ❌ no instalable: los polyfills 4.0 no admiten PHPUnit 10 |

Conclusiones:

- **R7:** la librería de tests de WordPress (también la de 7.1.3) solo funciona con PHPUnit ≤ 9, y PHPUnit ≥ 10 exige PHP ≥ 8.1. **PHPUnit 9.6** es la única versión válida para las dos puntas de la matriz, también para los tests unitarios sin WP (tienen que correr en PHP 7.4). Es la excepción a «última versión de todo» → ADR. Yoast polyfills (4.0.0) y wp-env (11.17.0) van en su última versión.
- **Hallazgo — `cli` frente a `tests-cli`:** `wp-tests-config.php` de wp-env usa la base de datos del contenedor y el prefijo `wp_`. Ejecutar la suite en `cli` instala las tablas de test **sobre el sitio de desarrollo**. Hay que ejecutarla en `tests-cli`.
- **Hallazgo — deprecación en wp-env 11:** al arrancar avisa de que el entorno de tests automático (`testsEnvironment`, `testsPort`, `env`) está obsoleto y se eliminará; la alternativa es un archivo de configuración aparte para tests con `--config`. La fase 1 debe usar ya ese modelo (un `.wp-env.json` de desarrollo y otro de tests con `testsEnvironment: false`), y comprobar que el `cli` de la config de tests no comparte base de datos con el de desarrollo.
